# GraphRAG 四模式冒烟审阅

- 构建时间：2026-07-20
- completion：`deepseek-v4-flash`（非思考模式）
- embedding：智谱 `embedding-3`（2048 维）
- 评测集：40 题；本次冒烟运行 Basic、Local、Global、DRIFT 各 1 题

| 模式 | 返回成功 | 来源落地 | 攻防区分 | 关系方向 | 不确定性/证据边界 | 审阅结论 |
|---|---:|---:|---:|---:|---:|---|
| Basic | 是 | 通过 | 通过 | 通过 | 通过 | 引用 OWASP 与 MITRE 来源编号，并明确“无万无一失的预防方法”。 |
| Local | 是 | 通过 | 通过 | 通过 | 通过 | 防御控制、攻击和受保护组件区分清楚，并说明分类器与过滤控制可能被绕过。 |
| Global | 是 | 通过 | 通过 | 通过 | 通过 | 按七个防御层次归纳，引用社区报告，并明确语料中的防御空白。 |
| DRIFT | 是 | 通过 | 通过 | 通过 | 需关注 | 多跳纵深防御回答完整并引用来源，但记忆版本控制等少量工程建议属于基于证据的推演，发布前应做逐条人工来源复核。 |

## 结论

四种查询路由均能返回非空、有索引引用的中文答案，技术冒烟通过。DRIFT 的综合方案适合作为设计草案，不应在缺少逐条来源人工复核时当作规范性结论发布。

图谱质量报告另发现 `PERSON` 2 个、`API` 1 个非预期实体类型，占 2973 个实体的约 0.1%。第一版保留并公开记录该偏差，下一轮应在抽取后增加七类 allowlist 校验或归一化步骤。
