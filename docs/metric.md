### 1. 传统知识抽取指标

作者在人工标注的测试集上，使用以下指标比较 BERT 方法与 LLM 方法：

* Macro-average Precision：抽取出的实体或关系中，有多少是正确的。
* Macro-average Recall：原文中应当抽取的实体或关系，有多少被成功识别。
* Macro-average F1 score：Precision 和 Recall 的调和平均，用于综合反映三元组级别的抽取质量。

这里采用宏平均，是为了对不同实体类别和关系类别进行相对均衡的评价。

需要注意，文献综述中还提到 AUC，但本文实际实验表格主要报告的是 Precision、Recall 和 F1，并未将 AUC 作为核心实验指标。

### 2. 图谱复杂度与冗余指标

这是文章专门提出的一组指标，主要评价图谱是否简洁、清晰，是否存在无意义的重复结构。

#### Entity Redundancy Rate：实体冗余率

衡量图谱中语义相同或高度相似的实体所占比例。

例如：

* “strong winds”
* “high winds”
* “rough weather”
* “adverse weather”

这些表达可能指向相同或相近概念，但被大模型抽取成不同节点。

作者先基于实体嵌入进行聚类，将潜在等价实体分组，然后计算：

[
\text{Entity Redundancy Rate}
=============================

\frac{\text{属于多成员等价簇的实体数量}}
{\text{实体总数量}}
]

该指标通常越低越好。

#### Relation Redundancy Rate：关系冗余率

作者将以下两类关系视为冗余或异常：

1. 同一实体对之间存在多个重复或冲突关系；
2. 自环关系，即三元组的头实体和尾实体相同。

例如：

[
\langle \text{heavy weather},
\text{characterizedBy},
\text{heavy weather}\rangle
]

关系冗余率定义为：

[
\text{Relation Redundancy Rate}
===============================

\frac{\text{冗余关系数量}}
{\text{关系总数量}}
]

该指标通常也是越低越好。

#### Graph Structure Complexity：图结构复杂度

作者使用图信息熵衡量结构复杂度和信息分散程度。

基本逻辑是：

* 先从事故子图中提取一条“主因果链”；
* 主因果链主要包含 `causes`、`exhibitedResponse`、`engagedInOperation` 等关键关系；
* 分别计算完整事故子图和主因果链的图信息熵；
* 比较主因果链在整个事故子图信息量中所占的程度。

图信息熵越高，通常表示：

* 节点连接分布更加分散；
* 图结构更加复杂；
* 图中包含的信息更加丰富。

但在本文中，复杂度并不是简单地“越低越好”或“越高越好”。作者关注的是主因果链是否占据图谱的主要信息内容：

* 过低可能说明图中存在大量边缘、冗余或无关结构；
* 过高则可能意味着图谱过度简化，遗漏辅助信息。

因此，它更适合作为“结构集中度与冗余程度”的诊断指标。

### 3. 语义准确性指标

#### Reconstruction Accuracy：文本重构准确度

这是本文最有特色的指标。

作者没有只检查单个三元组是否正确，而是采用以下流程：

1. 将一份事故报告对应的 SPO 三元组组成子图；
2. 将这些三元组输入另一个生成式大模型；
3. 让大模型根据图谱重构事故描述；
4. 比较重构文本与原始报告的语义相似度。

它反映的是知识图谱能否保留原文的整体语义、因果链和事件过程。

具体计算采用句子级匹配：

* 将原始文本和重构文本切分为句子；
* 对原始文本中的每个句子，寻找其与重构文本所有句子之间的最高余弦相似度；
* 最后对这些最高相似度取平均。

可以写成：

[
\text{Reconstruction Accuracy}
==============================

\frac{1}{N}
\sum_{i=1}^{N}
\max_j
\cos
\left(
\mathbf{u}_i,\mathbf{v}_j
\right)
]

其中：

* (\mathbf{u}_i) 是原始文本第 (i) 个句子的 BERT 向量；
* (\mathbf{v}_j) 是重构文本第 (j) 个句子的 BERT 向量；
* 使用 bi-encoder 生成句子嵌入；
* 使用 cosine similarity 衡量语义接近程度。

该指标越高，说明图谱对原始文本的语义保留越完整。

实验中作者还报告了重构准确度的四个统计量：

* Mean：所有事故子图的平均重构准确度；
* Max：最高重构准确度；
* Min：最低重构准确度；
* Std：重构准确度的标准差。

其中，Mean 和 Min 特别重要：

* Mean 反映图谱整体语义保真度；
* Min 可以暴露严重遗漏、幻觉或因果链断裂的极端案例；
* Std 越小，通常表示不同事故样本上的生成质量更加稳定。

### 总结

本文实际使用的指标体系可以整理为：

| 评价维度    | 指标                         | 主要衡量内容                   |
| ------- | -------------------------- | ------------------------ |
| 三元组抽取质量 | Macro Precision            | 抽取结果的正确率                 |
| 三元组抽取质量 | Macro Recall               | 原文知识的覆盖率                 |
| 三元组抽取质量 | Macro F1                   | Precision 与 Recall 的综合表现 |
| 实体结构质量  | Entity Redundancy Rate     | 同义、近义、格式变体实体的重复程度        |
| 关系结构质量  | Relation Redundancy Rate   | 重复关系、冲突关系和自环             |
| 整体图结构   | Graph Structure Complexity | 基于图信息熵衡量结构复杂度与主因果链集中度    |
| 全局语义质量  | Reconstruction Accuracy    | 图谱重构文本与原文的语义一致性          |
| 稳定性分析   | Mean、Max、Min、Std           | 重构准确度的整体水平、极端值和波动        |

这篇文章最值得借鉴的地方，是将传统的“局部三元组准确率”与“全局文本重构保真度”结合起来。对于你构建威胁情报或安全知识图谱的场景，可以将 Reconstruction Accuracy 改造成“由子图重构威胁事件描述，再与原始 CTI 报告比较”，从而检测三元组遗漏、因果链断裂和幻觉关系。
